## 1. 🚀 How to Push to GitHub

In your terminal inside `H:\swynex\SWYNEX-Frontend-Integration`:

```powershell
# 1. Initialize git
git init

# 2. Stage all files
git add .

# 3. Commit
git commit -m "feat: complete Task 3 frontend API integration with loading and error states for SWYNEX Technologies"

# 4. Set main branch
git branch -M main

# 5. Create a new public repository on GitHub (github.com/new) named:
#    SWYNEX-Frontend-Integration

# 6. Link to GitHub (replace with your account):
git remote add origin https://github.com/Catdas/SWYNEX-Frontend-Integration.git

# 7. Push to GitHub:
git push -u origin main
```

Your **Task submission link** will be:
`https://github.com/Catdas/SWYNEX-Frontend-Integration`
